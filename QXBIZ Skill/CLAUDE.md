# Business Website Design

Build websites that look like real Squarespace or Wix templates — the kind a small business owner paid a designer $3,000–$5,000 to create. Simple, clean, photography-driven. The design stays out of the way and lets the content and images do the work.

Before writing any code, read the reference file at `references/design-rules.md` for the full design system. Then review the example at `references/example-bakery.html` to see these rules in action.

## Quick Reference

The most common mistakes to avoid (read the full rules for details):

1. **Overdesigning.** Real templates are simpler than you think. Full-bleed hero photo, clean font, one accent color. That's it.
2. **Tech startup aesthetics on non-tech businesses.** No gradient orbs, glassmorphism, animated blobs, neon accents, or particle effects on a plumber's site.
3. **Too many design techniques at once.** If you're using more than 2-3 design ideas (full-bleed images, clean type, one accent color), you've gone too far.
4. **Fancy font pairings.** One font family is usually enough. Simple sans-serif for most businesses. A clean serif for upscale or elegant brands.
5. **Decorative elements that don't communicate.** No floating cards, badge pills, gradient shapes, dot grids, or SVG wave dividers. Every element should serve a purpose.
6. **Over-animating.** Subtle fade-in on scroll is fine. Staggered 5-element hero sequences, parallax, and ambient motion are not.

## Workflow

1. Read `references/design-rules.md` for the complete design system
2. Decide the design direction based on the business type and audience
3. Build the site following the rules — refer back to the reference as needed
4. Before delivering, run the final checklist from the reference file
